## Herunterladen

Mit dem GitHub-Konto anmelden, das auf dieses private Repository zugreifen darf. Einzelne Datei öffnen und oben rechts **Raw-Datei herunterladen** wählen. Alle Dateien zusammen: **Code → Download ZIP**.

Die HTML-Datei lokal im Browser öffnen. Das Offline-Paket vollständig entpacken und `index.html` öffnen. Bilder sind enthalten; für ihre Anzeige ist keine Internetverbindung nötig.

## Quellen und Bildnachweise

Die Recherche enthält Lageplan, Grundrisse, Schnitt und ein originales Ausführungsblatt. Eine eigenständige originale Ansichtszeichnung und belegte Baustellenfotos fehlen in den ausgewerteten zugänglichen Quellen. Historische Aufnahmen zeigen den gebauten Zustand.
