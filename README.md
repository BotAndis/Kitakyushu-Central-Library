# Kitakyushu Central Library

Recherche zu Arata Isozakis Bibliothek mit originalen Plänen, historischen Aufnahmen, allen acht Nutzerdateien und Quellenangaben.

- [Recherche-PDF · 25 Seiten](Kitakyushu-Central-Library.pdf)
- [HTML-Übersicht · Bilder direkt eingebettet](Kitakyushu-Uebersicht.html)
- [Offline-Paket · HTML mit Bilddateien](Kitakyushu-Offline-Paket.zip)

Zum Herunterladen die Datei auf GitHub öffnen und oben rechts **Raw-Datei herunterladen** wählen. Die HTML-Datei anschließend lokal im Browser öffnen. Das ZIP vollständig entpacken und `index.html` öffnen.

Eine eigenständige originale Ansichtszeichnung und belegte Baustellenfotos fehlen in den ausgewerteten zugänglichen Quellen. Historische Aufnahmen zeigen den gebauten Zustand. Die Pläne und Verlagsbilder behalten ihre ursprünglichen Rechte; Nachweise stehen im PDF und in der HTML-Übersicht.

Die Präsentation wird anschließend ergänzt. Autorenname: **Luca Ingui**.
